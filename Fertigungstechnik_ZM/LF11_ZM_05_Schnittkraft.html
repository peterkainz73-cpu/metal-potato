Aufgabe 5.1

Multiple Choice · TransferGrundlage ★

Begriffe. Beantworten Sie die Fragen.

  1. Was versteht man unter der spezifischen Schnittkraft kc? Wovon hängt sie ab?
  2. Welche Größen beeinflussen die Schnittkraft Fc?
  3. Wie hängen Schnittkraft und Schnittleistung zusammen?
  4. Was versteht man unter dem Wirkungsgrad einer Maschine?
Übertragen Sie: Welche Aussagen sind richtig? (mehrere richtig)
Musterlösung

Transfer: Halber Vorschub → dünnerer Span → kc steigt, Fc sinkt also weniger als auf die Hälfte. Pc = Fc · vc. Pc = η · P1 = 0,8 · 20 kW = 16 kW. kc von Aluminium ist deutlich kleiner als von Stahl.

a) Kraft zum Zerspanen von 1 mm² Spanungsquerschnitt; abhängig vom Werkstoff (Zerspanbarkeit) und von der Spanungsdicke h

b) Spanungsquerschnitt, kc (Werkstoff), Verschleiß/Schneidkantenform, Schneidstoff, vc, Spanwinkel γ

c) Pc = Fc · vc: Leistung = Kraft mal Weg pro Zeit; der Weg der Schneide pro Zeit ist vc

d) η = Pc / P1: Verhältnis abgegebene (Spindel-)Leistung zu aufgenommener Leistung; Verluste durch Reibung, Wärme

Stumpfe Schneiden erhöhen die Schnittkraft (Faktor ca. 1,3).

Aufgabe 5.3

BerechnungGrundlage ★

Welle aus 20MnCr5. Eine Welle aus 20MnCr5 wird von Ø80 mm auf Ø72 mm längsgedreht. κ = 57°, HM-Schneide neu und scharf, kc1.1 = 2140 N/mm², mc = 0,25. Der Spanungsquerschnitt darf höchstens 1,6 mm² betragen.

  1. Wie groß darf der Vorschub höchstens sein?
  2. Wie groß ist die Schnittkraft?
  3. Bestimmen Sie die Schnittleistung bei vc = 90 m/min.
Größe / AussageIhre Antwort
Vorschub f mm
Schnittkraft Fc N
Schnittleistung Pc kW
Musterlösung

a) ap = (80 − 72) mm / 2 = 4 mm; f = A / ap = 1,6 mm² / 4 mm = 0,4 mm

b) h = 0,4 mm · sin 57° = 0,335 mm; kc = 2140 / 0,335^0,25 = 2812 N/mm²; Fc = 1,6 mm² · 2812 N/mm² = 4499 N

c) Pc = 4499 N · 90 m / 60 s = 6749 W ≈ 6,75 kW

ap = 4 mm, f = A / ap, h = f · sin κ, kc = kc1.1 / h^mc, Pc = Fc · vc.

Aufgabe 5.4

BerechnungGrundlage ★

Maximale Schnitttiefe. Welche Schnitttiefe kann einer Drehmaschine mit 18,9 kW Antriebsleistung zugemutet werden? κ = 90°, η = 0,7, Werkstoff E295 (kc1.1 = 1990 N/mm², mc = 0,26), f = 0,5 mm, vc = 190 m/min, HM scharf und neu.

  1. Schnittleistung Pc
  2. spezifische Schnittkraft kc
  3. Schnittkraft Fc
  4. Spanungsquerschnitt A
  5. Schnitttiefe ap
Größe / AussageIhre Antwort
Pc kW
Fc N
A mm²
ap mm
Musterlösung

a) Pc = P1 · η = 18,9 kW · 0,7 = 13,23 kW

b) kc = 1990 / 0,5^0,26 = 2383 N/mm²

c) Fc = Pc / vc = 13 230 W / (190 m / 60 s) = 4178 N

d) A = Fc / kc = 4178 N / 2383 N/mm² = 1,75 mm²

e) ap = A / f = 1,75 mm² / 0,5 mm = 3,5 mm

Rückwärts rechnen: P1 → Pc → Fc → A → ap.

Aufgabe 5.5

BerechnungErweiterung ★★

Fräsen einer Alu-Platte. Ein 55 mm breites Werkstück aus AlCuMg1 (kc1.1 = 830 N/mm², mc = 0,23) wird mittig mit einem Walzenstirnfräser d = 75 mm, z = 8 (HSS-TiN, ohne Verschleiß) gefräst: ap = 10 mm, n = 1000 1/min, vf = 120 mm/min, κ = 90°.

  2. Vorschub je Zahn fz
  3. Mittenspanungsdicke hm
  4. Spanungsquerschnitt A je Schneide
  5. Zeitspanungsvolumen Q
  6. Schnittleistung Pc
Größe / AussageIhre Antwort
φs °
ze
fz mm
Q cm³/min
Pc kW
Musterlösung

a) sin(φs/2) = ae / d = 55 / 75 → φs = 94,3° (Tabellenbuch: ≈ 96°); ze = 8 · 94,3° / 360° = 2,10

b) fz = vf / (n · z) = 120 / (1000 · 8) = 0,015 mm

c) hm = 360° · 55 · 0,015 / (π · 75 · 94,3°) = 0,0134 mm

d) A = ap · hm = 10 mm · 0,0134 mm = 0,134 mm²

e) Q = ap · ae · vf / 1000 = 10 · 55 · 120 / 1000 = 66 cm³/min

f) kc = 830 / 0,0134^0,23 = 2239 N/mm²; Fc = 0,134 · 2239 · 2,10 = 627 N; vc = π · 75 · 1000 / 1000 = 235,6 m/min

Pc = 627 N · 235,6 m / 60 s = 2463 W ≈ 2,5 kW

ze wird nicht gerundet. Pc = Fc (alle Schneiden im Eingriff) · vc.
